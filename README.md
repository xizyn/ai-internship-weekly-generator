\# AI实习周记生成助手



这是一个基于 Python 和 Streamlit 开发的实习周记生成工具。



\## 功能介绍



\- 输入实习单位、实习岗位和实习时间

\- 自动计算实习总天数、周数、休息天数、到岗天数和总工时

\- 支持双休、单休、大小周、排休、自定义节假日等休息制度

\- 支持一键生成多周实习周记

\- 支持生成结果预览

\- 支持导出 Word 表格版周记
